KIPROTU 규정집 — 설치형 앱(PWA) 배포 안내
==========================================

이 폴더 전체를 인터넷 주소(https://)가 있는 곳에 올리면
조합원이 그 주소로 접속해 스마트폰에 앱으로 설치할 수 있습니다.
앱스토어 등록은 필요 없습니다.

※ 반드시 https 주소여야 설치·오프라인 기능이 작동합니다.
※ 파일 이름과 폴더 구조는 바꾸지 마세요.


1. 올리는 방법 (둘 중 하나)
------------------------------------------
[A] GitHub Pages (무료, 추천)
  1) github.com 가입 → 새 저장소(Repository) 만들기 (예: kiprotu-rules, Public)
  2) "uploading an existing file" 클릭 → 이 폴더 안의 파일 전부를 끌어다 놓기 → Commit
  3) 저장소 Settings → Pages → Branch를 main / (root)로 선택 → Save
  4) 1~2분 뒤 표시되는 주소(예: https://아이디.github.io/kiprotu-rules/)가 앱 주소입니다.
  ※ 노조 공용 계정으로 만들어 두면 집행부가 바뀌어도 인수인계가 쉽습니다.

[B] 노조 홈페이지 서버
  홈페이지 서버에 폴더를 하나 만들어(예: /rules/) 파일 전부를 그대로 올리면
  https://홈페이지주소/rules/ 가 앱 주소가 됩니다.


2. 조합원 설치 방법
------------------------------------------
  · 안드로이드: Chrome으로 앱 주소 열기 → 화면의 '설치' 버튼
              (안 보이면 ⋮ 메뉴 → '앱 설치' 또는 '홈 화면에 추가')
  · 아이폰: Safari로 앱 주소 열기 → 공유 버튼(□↑) → '홈 화면에 추가'
  설치하면 KIPROTU 아이콘이 생기고, 인터넷이 없어도 열립니다.


3. 규정이 개정되었을 때
------------------------------------------
  1) rules-data.js 파일에서 해당 규정의 history 맨 끝에 새 버전을 추가
     (파일 맨 위 설명 참고 — 개정 후 '전문'을 넣으면 신구조문 대비가 자동 생성)
  2) sw.js 파일 맨 위 VERSION 의 숫자를 하나 올림 (예: kiprotu-v1 → kiprotu-v2)
  3) 두 파일을 다시 업로드(덮어쓰기)
  → 조합원 앱은 다음에 인터넷 연결 상태로 열 때 자동으로 새 규정을 받습니다.

  ※ claude.ai 규정집 링크도 함께 쓰는 경우, 그쪽에도 같은 rules-data.js를 반영해야
    두 곳의 내용이 같아집니다.


4. 파일 구성
------------------------------------------
  index.html             앱 화면
  rules-data.js          규정 원문·개정 이력 (개정 시 이 파일만 수정)
  sw.js                  오프라인 저장 기능
  manifest.webmanifest   앱 이름·아이콘 설정
  icon-*.png, apple-touch-icon.png, favicon.png   앱 아이콘
  logo-en.png, logo-ko.png                        조합 로고
